📌 What is Inheritance?

Inheritance allows one object or class to reuse properties and methods from another. It is one of the core concepts of Object-Oriented Programming.

🧬 Prototype-Based Inheritance (Core JS)

JavaScript works internally using prototypes.


// Parent object
const user = {
    greet() {
        return "Hello User";
    }
};

// Child object inheriting from user
const admin = Object.create(user);

admin.role = "Admin";

console.log(admin.greet()); // Hello User
console.log(admin.role);    // Admin
JS checks properties in: object → prototype → prototype chain

🏗️ Class-Based Inheritance (Modern JS)


class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    introduce() {
        return `Hi, I'm ${this.name}`;
    }
}

class Student extends Person {
    constructor(name, age, course) {
        super(name, age); // call parent constructor
        this.course = course;
    }

    introduce() {
        return `${super.introduce()} and I study ${this.course}`;
    }
}

const s1 = new Student("Vivek", 20, "CSE");

console.log(s1.introduce());
extends → inherit class super() → access parent constructor & methods

⚡ Method Overriding


class Animal {
    speak() {
        return "Animal makes sound";
    }
}

class Dog extends Animal {
    speak() {
        return "Dog barks";
    }
}

const d = new Dog();
console.log(d.speak()); // Dog barks

Child class replaces parent method.

🔗 Prototype Chain Visualization


console.log(d.__proto__);              // Dog prototype
console.log(d.__proto__.__proto__);   // Animal prototype
console.log(d.__proto__.__proto__.__proto__); // null

This chain is how JS resolves properties.

📊 Real-World Example


class Vehicle {
    constructor(brand) {
        this.brand = brand;
    }

    start() {
        return `${this.brand} started`;
    }
}

class Car extends Vehicle {
    constructor(brand, model) {
        super(brand);
        this.model = model;
    }

    details() {
        return `${this.brand} ${this.model}`;
    }
}

const car = new Car("Tesla", "Model 3");

console.log(car.start());
console.log(car.details());

✅ Advantages

  • Code reusability
  • Cleaner structure
  • Easier maintenance

⚠️ Important Notes

  • JS is prototype-based (classes are syntactic sugar)
  • Always call super() before using this
  • Use inheritance only when there is a real relationship
